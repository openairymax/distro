# fw-exempt.txt —— 构建期固件预演（distro/ci/fw-preflight.sh）的豁免表
#
# 一行一条：<名字通配> <原因>。命中的缺件不计入 miss（该架构判为通过），
# 但每一条都会以 `exempt name=... reason=...` 打在日志里，并在后面的
# AIRYMAX-FW-PREFLIGHT 行给出重算后的 miss 计数——豁免不是静音，是记账。
#
# 收录规则只有三条，缺一不可：
#   ① 器件类别不在 0.0.4 硬件矩阵内（285H 实测硬件 + §8.18 的驱动清单）；
#   ② 固件包确实没有携带该文件，且原因不是本仓库的打包失误；
#   ③ 只缺同一驱动的型号变体时，矩阵内型号的固件必须已在包内、可核对。
#
# 表外的新缺件一律判负。加行前先问：这是「本版不支持这类器件」，还是
# 「我们漏装了」？后者必须修安装清单，不能写进这里。
#
# 台账来源：image-build run 42797570216 第 19 步四架构预演（x86_64 110 条、
# aarch64 36 条、riscv64 0 条、loongarch64 55 条缺件）与 285H 实机硬件矩阵
# （无线 Intel BE200 + Realtek RTL8852BE、蓝牙 Intel btintel、显卡 i915/xe、
# 音频 SOF、摄像头 IPU6）。
# ===========================================================================
